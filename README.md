# 云知 · 校园气象生活助手（演示原型）

对照《初赛作品材料（模板 1）》骨架实现的可交互 demo，覆盖「位置级天气决策」与「云景观测记录」两条链路。

在线演示：<https://mgy7r6nmh5-beep.github.io/yunzhi-campus-weather/>

## 怎么运行

双击 `index.html` 即可，无需安装依赖、无需构建。

首次打开会请求一次 open-meteo（免密钥）实时气象接口；若网络不可达，页面自动标记为「示例数据 · 非实时」或「过期缓存」，不会静默编造数值。

建议用 Chrome / Edge 打开。`file://` 下若接口被浏览器拦截，直接点右上角「模拟接口失败」即可完整演示降级路径。

## 目录

```
index.html          页面结构（含内联 SVG 图标库）
css/style.css       天空场景、玻璃卡片、响应式
js/data.js          位置知识表（14 处校内 + 2 处校外）、云型表、禁用词表
js/weather.js       实时取数、10 分钟缓存、stale 回退、示例兜底
js/engine.js        判断规则、数值白名单审计、云景记录生成与追问
js/app.js           渲染与交互
```

## 关键设计

**数值只来自接口。** 位置知识只影响判断权重（`factors.wind / sun / slip`）与提示文案，不改写任何气象数值；界面上温度、风速等全部来自接口字段。

**输出层零数值。** 结论文案用模板句生成，天然不含数字；审计函数仍按模板规则扫描阿拉伯数字、中文数字与「数字+单位」组合，任何命中即判定失败并展示原因。

**降级即保守。** 接口失败时白名单为空集合，输出「不建议 / 谨慎」类保守建议并标注数据不可用，不做数值推测。

**位置可扩展。** 新增位置只需在 `js/data.js` 的 `LOCATIONS` 追加一条（坐标、因子、提示），无需改动引擎与页面。

## 正式版需要替换的部分

| 占位 | 正式实现 |
|---|---|
| 规则引擎生成文案 | ModelArts 上的 LoRA 适配器推理（提醒 / 笔记两个接口） |
| 云型手动选择 | ModelArts 图像分类返回候选云型与置信度，低置信转人工确认 |
| localStorage 打卡册 | RDS 持久化 + 用户修正标记回写 |
| 本地缓存 | Redis 缓存与 stale 降级 |
| 演示模式标注 | 接入真实推理后移除 |
